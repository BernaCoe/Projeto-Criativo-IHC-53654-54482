# Jazzia - Gera, Toca e Jazz (Baseado no motor Generative Jazz)

Esta é uma aplicação React desenvolvida para a geração progressões de acordes, baseada na GenJazz API. Foi desenvolvida por Bernardete Coelho (53654) e Inês Menezes (54482) no âmbito da unidade curricular Interação Humana com o Computador, do curso de Engenharia Informática da Universidade da Beira Interior, no ano letivo 2025/2026. O seu desenvolvimento terminou a 31 de maio de 2026. 

## Funcionalidades
* Geração de progressões musicais personalizadas.
* Gestão de sequências guardadas com persistência local (IndexedDB).
* Sincronização com API externa.
* Autenticação de utilizadores via Clerk.
* Interface otimizada para dispositivos móveis.

## Pré-requisitos
Certifica-te de que tens instalado:
* **VS Code**
* **Node.js** (v18 ou superior)
* **npm** (gestor de pacotes do Node)
* **Browser** (Chrome, idealmente)

## Instalação e Execução

Abre no VS Code a pasta jazzia e executa os seguintes comandos.

Se ainda não estiveres dentro da pasta 'jazzia', faz primeiro este comando. Se já estiveres dentro da página, avança para os seguintes.
```bash
cd jazzia
```
```bash
npm install
npm start
